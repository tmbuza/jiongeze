Quick Computer Guide

Computers help people learn, communicate, create, and organize information.

This page provides a simple reference for important computer concepts.

Note

You do not need to memorize everything.

Practice helps things become familiar.

Main Computer Parts

Part Purpose
Screen (Monitor) Displays information
Keyboard Used for typing
Mouse Used for selecting and clicking
Power Button Turns the computer on or off
Speakers Play sound
USB Port Connects devices

Common Mouse Actions

Action Purpose
Single Click Select an item
Double Click Open an item
Right Click Show options
Scroll Move up or down

Common Keyboard Keys

Key Purpose
Enter Move to new line or confirm action
Space Bar Create spaces
Backspace Remove text
Shift Create capital letters
Delete Remove selected items

Code

A[Turn On Computer]

E --> F[Close File]
